# Legally Lite static rebuild

This directory contains the standalone reconstruction of Legally Lite based on the original product walkthrough.

## Run locally

From this directory:

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173.

No build step or external API keys are required. Progress is stored locally in the browser.

## Included

- responsive editorial-style interface
- dashboard and challenge filters
- consumer-rights quiz with explanations
- legal concept sorting mini-game
- multi-step tenant-rights scenario
- context-aware educational assistant
- profile, mastery, badges, and leaderboard
- dark mode and accessibility controls
